What is Preset Voices?

Choose from 9 built-in AI speakers (Ryan, Vivian, Aiden, etc.) to generate speech. Each speaker has a unique voice optimized for specific languages.

Best for: Quick voice generation with consistent, high-quality speakers.

What is Voice Design?

Describe the voice you want (e.g., "A deep, calm male voice with a British accent") and the AI will create it for you.

Best for: Creating custom voices for characters, specific moods, or unique speaking styles.

Choose a speaker that matches your text language for best results

Tip: Match your text language to the speaker's native language

Guide the AI on how to deliver the text - tone, emotion, style

Preset Voices API

// POST /tts/custom - Generate speech with preset voice with a built-in speaker

curl -X POST http://localhost:8000/tts/custom \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Your text here",
    "speaker": "Ryan",
    "instruct": "Speak with excitement",
    "format": "wav"
  }'

Response

// Returns: WAV audio file (audio/wav)

HTTP/1.1 200 OK
Content-Type: audio/wav
Content-Disposition: attachment; filename=tts.wav

Voice Design API

// POST /tts/design - Generate speech with custom voice description

  -H "Content-Type: application/json" \
  -d '{
    "text": "Your text here",
    "instruct": "A deep, calm British male voice with authority",
